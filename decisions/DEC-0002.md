# DEC-0002 — Exclude M12 from Construction

Status: accepted
Date: 2026-09-25

## Decision

M12 is reference-only and excluded from the Agentic SDLC and 12-module construction order.

## Reason

The executable prompt explicitly requires this boundary. M12 supplies the target SRE architecture and stack as source evidence rather than as a build capability.

## Consequence

The target project must acquire M12-informed capabilities through the other modules plus explicit project labs; M12 is not counted as a thirteenth build stage.
