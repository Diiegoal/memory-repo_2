# DEC-0005 — PostgreSQL plus Evaluated pgvector

Status: accepted
Date: 2026-09-25

## Decision

Use PostgreSQL as authoritative operational storage and evaluate pgvector before adding a separate vector database.

## Reason

The product requires relational incident/audit data and semantic retrieval of runbooks/history. pgvector can consolidate both concerns in one system. This remains subject to future scale validation.
