# Órdenes candidatas evaluadas

## Criterio

Chat 1 comparó tres órdenes con escala 1–5. Las puntuaciones son una evaluación profesional documentada, no una medición empírica. Chat 2 las conserva como estado heredado.

## Candidato A — Construcción profesional

`M1 → M3 → M4 → M2 → M6 → M5 → M7 → M8 → M9 → M10 → M11 → M13`

Alinea harness, producto, contrato, seguridad, arquitectura, calidad, datos, implementación, QA y entrega.

## Candidato B — Security-first

`M1 → M3 → M4 → M6 → M2 → M5 → M7 → M8 → M9 → M10 → M11 → M13`

Adelanta seguridad, pero puede analizar amenazas antes de disponer de capacidades totalmente delimitadas.

## Candidato C — Pedagógico adyacente

`M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9 → M10 → M11 → M13`

Sigue una progresión conceptual más cercana a títulos, pero altera relaciones funcionales del workflow profesional.
