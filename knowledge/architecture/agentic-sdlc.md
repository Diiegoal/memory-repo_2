# Agentic SDLC

## Definition

For this investigation, **Agentic SDLC** means the ordinary software development life cycle executed with AI as a first-class engineering capability. It is not a replacement lifecycle and not merely the course order.

## Construction phases

1. Foundation — M1
2. Working AI harness — M3
3. Discovery and planning — M4
4. Specification — M2
5. Security/privacy by design — M6
6. Architecture and living knowledge — M5
7. Unit-level quality — M7
8. Data foundation — M8
9. Backend implementation — M9
10. Frontend/operator experience — M10
11. Integration/system QA — M11
12. Delivery and operations — M13

## Why this is agentic

The agent participates in:

- exploration;
- planning;
- spec interpretation;
- code generation;
- test generation;
- documentation generation;
- review assistance;
- operational evidence gathering;
- incident investigation;
- controlled remediation.

But human gates remain where the impact or ambiguity requires them.

## Iterative loops

- backlog refinement ↔ specs
- security ↔ architecture
- docs ↔ implementation
- tests ↔ implementation
- incident evidence ↔ postmortem ↔ runbook/RAG
- deployment ↔ observability ↔ recovery verification
- agent traces/evals ↔ prompt/tool/context changes

## M12 boundary

M12 is a source of information about the target SRE/DevOps system. It is not one of these phases.
